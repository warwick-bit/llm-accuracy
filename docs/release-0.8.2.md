# Accuracy 0.8.2

_26 October 2026. The [published release](https://github.com/warwick-bit/llm-accuracy/releases/tag/v0.8.2)
identifies the marketplace merge commit and provides the ZIP and checksum._

The numerical helper accepts explicitly named monetary metrics in its growth
and every-region forms, plus a percentage ratio with source-defined numerator
and denominator series. It retains exact currency/population binding and integer
rounding. Business definitions, source completeness and currency conversion are
not inferred. Existing revenue inputs remain supported.

Accuracy Doctor lists the skills shipped in the inspected package and checks
their entrypoint/frontmatter. Package presence is distinct from host listing or
current-session activation; unavailable host evidence remains unverified.

Fresh local qualification used native Windows with Git Bash, Python 3.13.1 and
Claude Code 2.1.287. The [current compatibility receipt](validation/compatibility-candidate.json)
records clean installation, upgrade, live Accuracy hook delivery, invalid-Python
recovery and uninstall against the 0.8.2 package. The
[installation and archive receipt](validation/claude-code-smoke-0.8.2.json)
records exact installed-file matching and four bounded Sonnet 5.5 sessions.
Temporary profiles were cleaned up; normal user configuration was not changed.

Publication requires the four native installation CI jobs (Linux, macOS and
Windows with and without Bash), the marketplace publication check and the
required release-gates aggregate. These hosted checks execute installed hooks
directly; they do not establish live model delivery on the other hosts.

Desktop Chat, Desktop Code UI and Cowork delivery remain unverified. These
checks establish installation and delivery, not a general accuracy improvement.
The [0.8.1 qualification](release-0.8.1.md) remains historical evidence for that
version only.
